# 路线图

## P0 已完成（v0.1 骨架）

- 配置解码：JSON / gzip / BOM / `**`Base64 / `2423`
- 多仓加载 + 相对路径解析
- CMS 通路（type 0/1/4）
- JAR 宿主（`csp_`，DexClassLoader，自有 ABI）
- 首页 / 详情 / 播放 / 设置
- 海报 L0 源图 URL 升级（豆瓣 / TMDB / B站 / BCE，零请求）
- 海报 L1 B站 PGC 兜底（无 Key）+ 频控 / 负缓存 / 磁盘缓存
- TMDB 保守匹配增强（可选，需自备 Token）
- 设置页：海报增强开关、清空海报缓存

**验收**：一份 CMS 配置可在真机走通「首页 → 详情 → 选集 → 播放」；一个常见 JAR 插件可打开首页。

1. JAR 迁到 `:spider` 子进程，插件崩溃不影响 UI；
2. 接入 QuickJS（`.js` / `.mjs` 插件），最小 `net.req` / `Spider` base；
3. ~~搜索页~~（已完成，拼音首字母仍可选）；
4. ~~观看历史 / 继续观看卡片~~（已完成，用 JSON 落盘替代 Room）；收藏待做；
5. ~~焦点恢复、背景交叉淡入~~（已完成）；
6. 插件下载进度与失败重试 UI。

**验收**：10 个常见 JAR + 3 个 JS 插件跑通；连续开关 20 次详情不 OOM；插件崩溃后应用可继续使用。

## P2 完整度（2–3 周）

1. 直播（M3U/TXT）与频道表；
2. 备份/还原（`nextmovie-backup` 自有格式）；
3. 播放增强：倍速、字幕、音轨、片头跳过；
4. 源健康检查（逐源探活 + 结果可读）；
5. Python 插件（Chaquopy）评估，注意授权与包体。

## P3 打磨

1. 主题与配色自定义；
2. 多端同步（WebDAV，可选）；
3. 性能回归基准（启动/滚动/内存）；
4. 无障碍与对比度审计。

## 明确不做

- 不内置任何影视源、订阅地址、直播源；
- 不做 DRM 绕过、不做付费内容解锁；
- 不收集用户数据。
