# 电视交互与性能验证（2026-11-24）

当前开发版：0.6.10-dev / versionCode 26。构建产物：tv、tv64、dev Debug APK。

## 实现

- 按屏幕宽度归一到 960 逻辑 dp，设置中提供标准、大、特大缩放。海报墙约五列，放大文字与选集按钮。
- 统一可见白色焦点框。首页方向键保持列位置，边缘不横向绕行；返回首页恢复栏目与海报。详情左右区独立滚动，初始聚焦播放；播放页支持方向键唤出工具栏、快退/快进/暂停及返回。
- 设置提供手机扫码导入：同一局域网临时网页，五分钟有效，随机会话令牌、来源检查与请求限制。手机提交后由电视确认加载。二维码内容的生成及解码、HTTP 提交与拒绝无效请求有自动化验证；未使用实体手机完成扫码。
- 插件账户窗口与 SpiderService 共享 :spider 运行时；支持插件原生 Activity 对话框和同步 Spider.dialog(JSON) 宿主接口。源列表提供账户/网盘入口。账户页返回后刷新内容缓存。
- 首页/分类/详情限时内存缓存、并发请求合并；首页与分类标签共用一次插件 home 调用；磁盘保留五分钟首页快照和上次配置以缩短重新启动等待。
- 已知视频文件跳过多余 HLS 探测，未知类型探测限制三秒与读取量。播放 URL 不持久缓存。记录 home-ready、detail-ready、first-frame 耗时以便后续定位。

## 验证与测量

环境：本机 Android 11 x86_64 模拟器，启用 ARM 转译。尚无真实电视/遥控器硬件验证。

81 个单元测试全部通过，0 失败、0 跳过（包含外部配置样本）；tv、tv64、dev 三个 Debug 变体构建通过。

肥猫配置中“豆瓣预告 / csp_YGP”一次实际探测：

| 数据操作 | 时间 |
| --- | ---: |
| 首页首次调用 | 3317 ms |
| 首页内存缓存命中 | 1 ms |
| 详情调用 | 306 ms |
| 播放 | 已进入 playing |

这组时间为单个源的本地一次观测，不含所有图片绘制，也不能代表全部来源或网络环境。原始记录位于 artifacts/tv-fixes/timing-probe.json。

纯方向键首页回归：沙丘 → 右：悲伤逆流成河 → 下：指尖谋杀 → 左：时间里的爱人 → 上：沙丘。结果与截图位于 artifacts/remote-smoke。确认详情默认播放按钮获得焦点，播放页方向键唤出工具栏并聚焦“暂停”。同一次界面日志记录首页 ready 1086 ms、详情 ready 850 ms、播放首帧 1338 ms；ready 指数据就绪，不代表全部图片绘制。

4K 分辨率切换检查的自动审批等待超时，命令未执行，未计为通过；当前已确认的截图为 1920×1080。已确认模拟器恢复原始分辨率，并移除测试用端口转发。

网盘账户：饭太硬配置的 MDrive 插件已通过方向键打开“登入自己网盘”、提供商选择及原生图片二维码窗口。未扫码授权，未验证登录成功后的账户资源播放。未保存认证二维码图片。

## 范围与限制

- 插件账户兼容取决于插件具体宿主接口；未实现全部私有 SDK 或所有 dialog 回调重载，不代表所有网盘来源通用登录。
- 扫码导入需要手机与电视网络互通；隔离 Wi-Fi、模拟器 NAT 等环境可能需要局域网桥接。
- 已有四份目标配置的代表来源验证见 COMPATIBILITY-2026-11-24.md；并非全部站点可用保证。
- 开发包为 Debug 签名，本轮未发布到远端、未提交 Git。
