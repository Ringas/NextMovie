# 界面信息架构（遥控器 + 键盘）

## 主导航（左侧轨，5 项）

| 顺序 | 项 | 职责 |
|------|-----|------|
| 1 | 首页 | 分类海报墙、继续观看 |
| 2 | 搜索 | 跨站搜索 |
| 3 | 片库 | 收藏 + 历史（二级用顶栏切换） |
| 4 | 网盘 | 网盘浏览（账号在设置里配） |
| 5 | 设置 | 全部系统项 |

**舍弃的主导航形态**：底部 Tab、汉堡多级抽屉（不适合 10-foot / 遥控）。

## 设置左栏（6 段，合并后）

| # | 段 | 保留内容 | 说明 |
|---|-----|----------|------|
| 1 | 片源 | 订阅 URL、站点列表、海报解析 | 最常用，置顶 |
| 2 | 播放 | 连播、解码模式、失败软解/换线、源预热 | 解码相关集中 |
| 3 | 外观 | 柔光、主题强度、海报取色 | 纯观感 |
| 4 | 连接 | 网盘账号 + WebDAV（原两段合并） | 减少侧栏噪音 |
| 5 | 数据 | 收藏/历史清理、缓存重建 | 危险操作单独段 |
| 6 | 关于 | 版本、开源说明、**快捷键一览** | 帮助入口 |

## 设置项：新增 / 保留 / 舍弃

### 保留
- 订阅与站点
- 自动连播
- 解码模式（自动 / 硬解 / 软解）
- 解码失败自动软解、失败自动换线
- 源预热
- 外观柔光
- 网盘 / WebDAV
- 清空收藏、历史、海报缓存、内容缓存
- 版本信息

### 新增
- 设置内 **快捷键说明**（遥控 vs 键盘对照）
- 左栏 **数字键 1–6** 跳段（键盘）
- 统一菜单行焦点环（`TvMenuItem` / 强化 `tvClickable`）

### 舍弃（UI 不再露出）
- **弹幕开关**（不排期，配置键保留默认关）
- 设置里强调 DRM / IJK / MPV（仅文档）
- 重复的「清缓存」入口（海报清在数据段一处即可）
- 过长技术说明堆在主路径（改短文案 + 文档）

## 按键约定

| 动作 | 遥控 | 键盘 |
|------|------|------|
| 确认 | OK / 中键 | Enter / 空格 |
| 返回 | 返回 | Esc / Backspace |
| 菜单 | 菜单键 | Tab / Context |
| 导航 | 方向键 | 方向键 |
| 设置跳段 | — | 1–6 |
| 播放暂停 | 播放键 | Media / 空格（播放页） |

全局：`TvKeys` / `TvAction`；可点控件：`tvClickable`（含确认键兜底）。
