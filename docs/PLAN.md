# UI 重构专项计划（v0.4 起）

> 本文件是 `ROADMAP.md` 的补充：ROADMAP 管功能版图（P0–P3），本文件只管“把界面从原型做到产品级”的排期与验收。

## 现状审计（0.3.6）

| 模块 | 现状 | 判定 |
|---|---|---|
| 配置解码 / 多仓 / 导航页跳转 | 6 种编码全支持，4 个真实源实测可用 | 可用，冻结 |
| 插件宿主（:spider 进程 + DexClassLoader） | 纯 Java 插件可跑（肥猫 41 站），Guard 系 ARM-only 不可跑 | 够用，只修 bug |
| CMS 通路（type 0/1/4） | 可用 | 可用 |
| 首页 | Hero 大图 + 一条“最近更新”轨道 | **毛胚**，无分类/无骨架屏/无空态 |
| 详情 | 标题 + 简介 + 线路 chip + 选集 | **毛胚**，无演职员/相关推荐/剧集网格 |
| 播放 | ExoPlayer + 极简 HUD | **毛胚**，无进度条交互、无倍速/选集抽屉 |
| 搜索 | 自绘九宫格键盘 + 结果网格 | 功能齐，视觉毛胚 |
| 设置 | 长列表文本 | **毛胚**，无分组卡片/无开关控件 |
| 键鼠 | 悬停聚焦、滚轮、Esc/右键返回、物理键盘输入 | 已完成，待细节打磨 |
| 视觉系统 | 只有颜色 token，无字号阶梯/间距体系/动效规范 | 缺失 |

UI 代码合计约 2000 行 / 5 屏，等于“能跑的原型”，不是产品级界面。

## 策略调整

1. **源兼容冻结**：只修可复现的真 bug；Guard 源留给 ARM 真机，不再投入时间。
2. **重心转向产品**：先把“能看片”的闭环做对，再做视觉。
3. **每个里程碑以截图验收**，不靠口头描述。

## 里程碑

### M1 闭环（0.5–1 天）v0.4.1
- 列表 → 详情 → 选集 → 播放 全链路在纯 Java 插件 / CMS 站跑通
- 详情页：线路切换保留、剧集网格（多于 20 集折叠）、封面/评分/年份/简介布局重排
- 播放器：进度条可聚焦拖动、倍速、选集抽屉、上一集/下一集、播放失败可读提示
- 全局状态：加载骨架屏、空态、错误态（重试/换站点）、Toast 统一
- 验收：4 张截图（首页/详情/选集/播放）

### M2 首页视觉重构（1 天）v0.4.2
- Hero：背景图 + 底部渐变遮罩 + 标题/元信息/简介限 3 行 + 「播放」「详情」双按钮
- 分类 Tab（首页推荐 / 电影 / 剧集 / 动漫 / 综艺，来自站点分类接口）
- 横向轨道：轨道标题 + 右侧「全部 ›」，聚焦卡片放大 1.06 + 边框光晕 + 阴影
- 海报：统一 2:3 比例、缺图占位（渐变 + 片名首字）、评分角标统一右下
- 顶部栏：站点名、状态徽标、搜索、设置，聚焦有下划线指示
- 验收：3 张截图（默认态 / 聚焦态 / 滚轮滚动后）

### M3 详情 / 播放 / 设置视觉（1 天）v0.4.3
- 详情：全屏背景 + 左信息右海报、线路 tab 重绘、剧集横向 grid、相关推荐轨道
- 播放 HUD：底部渐变条 + 时间轴 + 图标按钮组，3 秒无操作淡出
- 设置：分组卡片（数据源 / 海报 / 缓存 / 关于），开关与输入框统一控件，站点列表带类型徽标（CMS / 插件 / 需 ARM）
- 验收：4 张截图

### M4 细节打磨（0.5 天）v0.4.4
- 字号阶梯（12/14/16/20/28/44）、间距 8 栅格、圆角/阴影统一
- 动效：聚焦 180ms、页面切换 240ms crossfade、HUD 淡入淡出
- 键鼠：hover 与 DPAD 焦点互不抢、滚轮步长按轨道/页面区分、右键返回全覆盖
- 验收：交互 GIF/连续截图

### M5 真机与发布
- ARM 真机装 0.4.x，验证 Guard 源（in.bmp / 饭太硬 / 王二小）
- README 补截图、构建说明、源兼容说明；打 release 签名包

## 风险
- 纯 Java 插件站点普遍只实现首页，详情/播放闭环需要挑选支持 detail 的插件站（荐片/瓜子/360 官源等）。
- 部分 CMS 站已失效，需要准备 2–3 个备选。
- 模拟器 GPU 软渲染，滚动动效会掉帧，视觉节奏以真机为准。
