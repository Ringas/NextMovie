# UI 重构说明（客厅简化版）

## 目标
电视十尺 UI：信息架构扁平、焦点路径可预期、视觉噪音少。

## 结构
```
MainShell
├── NavRail（左 92dp：首页 / 搜索 / 片库 / 网盘 / 设置）
└── Content
    ├── HomeScreen：顶栏 + 分类条 + 继续观看 + 海报网格
    ├── Search / Library / Netdisk / Settings
```

## 交互原则
1. 全局只有左侧 5 个一级入口，不再顶部多层胶囊导航
2. 首页：换源 / 搜索 / 刷新三颗明确按钮
3. 分类横向一排；内容用网格（4–6 列），避免超长横向轨道
4. 焦点放大 1.08 + 白边描边（PosterCard）
5. 背景柔光由壳层统一绘制

## 未改动的业务
详情页、播放器、源解析、配置解密等逻辑保持原链路。
